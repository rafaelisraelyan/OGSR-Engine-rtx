## 4. Combined multi-NPC + reload runtime

Точные аргументы:

```text
-multi_instances -start "start server(all/single/alife/new) client(localhost)"
-physx_ragdoll sim_default_stalker_2 -physx_ragdoll_smoke
-physx_ragdoll_multi -physx_ragdoll_reload
```

Лог: `artifacts/final-acceptance/xray_gr_26-10-26_05-13-28.log`
(финальный Release-бинарник, собран в 05:13:21).

Счётчики по всему логу:

```text
multi result=3
multi spawned=3
multi second hit=3
multi third hit=3
multi destroying first=3
PhysX ragdoll created bodies=11 joints=10=6
owner committed=6
releasing PhysX owner state=6
PhysX ragdoll instance released=3
ragdoll reload 1/2=1
ragdoll reload 2/2=1
ragdoll reload 3/2=0
reloading level=2
tick frame=1=6
Unhandled exception=0
ScriptCrashHandler=0
```

Каждая из трёх сессий (старт + reload 1 + reload 2) повторяет один сценарий:

1. Первый NPC получает PhysX: `created bodies=11 joints=10 bones=47`,
   `owner committed`.
2. Второй NPC убит при активном PhysX instance → ODE fallback:
   `multi second hit ... physx_instance=1`, в результате `second=1 shell=1`.
3. Первый NPC уничтожен → `multi destroying first PhysX NPC`,
   `releasing PhysX owner state`, `PhysX ragdoll instance released`.
4. Третий NPC убит после освобождения слота:
   `multi third hit ... physx_instance_before=0`, затем новое
   `PhysX ragdoll created bodies=11 joints=10`; в результате `third=1 shell=0`,
   `physx_instance=1`.
5. `multi result second=1 shell=1 third=1 shell=0 physx_instance=1` — двойного
   solver ownership нет.
6. `ragdoll reload N/2 requested` → `reloading level`; после загрузки снова
   `tick frame=1`, что подтверждает сброс process-static smoke-состояния.
7. После `2/2` третий reload не запрашивается (`ragdoll reload 3/2=0`).
