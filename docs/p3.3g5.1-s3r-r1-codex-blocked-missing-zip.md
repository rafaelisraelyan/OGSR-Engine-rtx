## Узкое наблюдение по исходнику, не вывод о новом evidence

В source pin `ogsr_engine/xrGame/ogsr_physx_runtime.cpp:42–44` заданы 8 static tiles, 65536 суммарных и 16384 на tile. В `readStaticFragmentTile` (`:1046–1114`) поле `sourceTriangles` — **число треугольников до фильтра принадлежности по centroid**; непосредственно ограничение проверяет отдельный `triangleCount` уже после фильтра. Следовательно, само значение `src_tris=73116` не определяет точное число треугольников, принадлежащих tile. Если в старом журнале корректно зафиксирован также `truncated=1`, эта ветвь означает, что при фильтрации было найдено больше 16384 подходящих треугольников. Новые R1 counts и эффективность альтернативных лимитов без ZIP не проверены.

Код `ensureStaticTileAt` (`:1428–1530`) кэширует успешные tiles; при неудачном извлечении немедленно возвращает false без добавления этой записи в успешный кэш, что допускает повторную попытку при последующих запросах. Проверку total budget выполняет перед `sceneAddStaticFragment`. Это источник для дальнейшего анализа, а не доказательство фактических частот повторной обработки или безопасности предлагаемого production patch.
