## 1. HUD lifecycle

Исправлено в `ogsr_engine/xrGame/ogsr_physx_ragdoll.cpp`:

- `CHUDManager::IsRenderable()` — поддерживаемое чтение фактического
  состояния HUD (добавлен getter в `HUDManager.h`).
- `hideSmokeHud()` сохраняет `HUD().IsRenderable()` и полный `psHUD_Flags`,
  затем скрывает HUD.
- `restoreSmokeHud()` восстанавливает **только** то, что было изменено
  диагностикой; ownership-флаги `g_smokeHudRenderableSaved` /
  `g_smokeHudFlagsSaved`.
- Убран безусловный `HUD().SetRenderable(true)`.
- Повторный `stopSmokeCamera()` — no-op (`HUD restore skipped (no ownership)`).
- `OgsrPhysXRagdollRelease()` без camera smoke не меняет HUD.
- Level unload/reload вызывает `OgsrPhysXRagdollSmokeCameraStop()`; cleanup
  выполняется до уничтожения HUD.
- При отсутствии `g_hud` меняются только `psHUD_Flags` (если ownership есть).

## 2. Capture timing

Тайминг привязан к PhysX `stepIndex`, а не к `Device.dwFrame`:

| Target step | Время |
|---:|---:|
| 0 | 0.00 с |
| 10 | 0.10 с |
| 50 | 0.50 с |
| 100 | 1.00 с |
| 200 | 2.00 с |
| 400 | 4.00 с |
| 600 | 6.00 с |

Фактические шаги (финальные логи):

```text
8 Н·с:  pre 0, 10, 50, 100, 200, 400, 600; CAPTURE_COMPLETE max_delta=0
40 Н·с: pre 0, 10, 50, 100, 200, 400, 600; CAPTURE_COMPLETE max_delta=0
```

Логируются `target_step`, `actual_step`, `delta`, `time`. При пропуске
целевого шага кадр помечается отклонением; если delta > 5 — статус
`CAPTURE_INCOMPLETE`. NPC не уничтожается до `g_smokeCaptureComplete`.
После последнего кадра — `stopSmokeCamera()` и штатный cleanup.
