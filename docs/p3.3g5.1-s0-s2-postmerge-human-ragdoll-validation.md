## 2. Source-verified test mode and flags

Based on the merged `ogsr_physx_runtime.cpp::parseRagdollFlags`:
- `-physx_all_humans` by itself sets the experimental all-human selection, V2 multi-instance and free-ragdoll handoff. It is **not** necessary to also use `-physx_ragdoll_multi`.
- `-physx_max_ragdolls N` has **allowed bounds 2…40**, initial default **2**. A stage with only one corpse still uses cap 2, not an invalid cap 1.
- `-physx_ragdoll_multi` **conflicts** with V2 multi-instance mode and disables that requested path: **do not combine with `-physx_all_humans`**.
- `-physx_static_tiles` requests tile-based coverage. Without it the current all-human path uses global V2 static bounds, and missing world coverage must still fail safely to ODE.
- `-physx_all_humans` does not automatically enable compile-time `OGSR_PHYSX_RAGDOLL` or physically place required DLLs on disk. Build properties, V2 loader symbol resolution, actual runtime initialization and game-side NPC eligibility must be confirmed separately.

Record exact launch command, parsed flag diagnostic lines, `-physx_max_ragdolls` effective value and static coverage mode. Do not auto-enable all-human mode in shipped/default builds.
