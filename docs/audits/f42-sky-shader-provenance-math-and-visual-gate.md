## Phase B — mathematical correctness review (READ-ONLY first)
Find exact source lines, units, conventions, macros and produce CPU reference + small deterministic test vectors. Relevant standard reference relations, **not a claim about the current shader**:
- Nonnegative extinction `sigma_t` in inverse world-distance units and density `rho >= 0`. Segment optical thickness `tau_i = sigma_t * rho_i * Delta_s_i`. `T_{i+1} = T_i * exp(-tau_i)`. For a uniform segment, `a_i = 1-exp(-tau_i)`. Verify `T in [0,1]`, `L >= 0`, monotonicity of T and invariance under subdividing a constant-density segment. Avoid spurious missing/double `Delta_s` factors.
- With single scattering and a segment-averaged source function `S_i`: `L_{i+1} = L_i + T_i * (1-exp(-tau_i)) * S_i`; `S_i` must account for albedo, sun/ambient and phase with a documented normalization. If using a differential-step integration instead, verify its convergent limit and consistent units. Do NOT multiply density/step twice.
- Sun-ray extinction: `T_sun = exp(-integral(sigma_t * rho * ds))`, using the same canonical density/weather profile and documented light-ray step distances; test camera and light rays through a constant slab.
- Henyey–Greenstein candidate: `p(mu,g)=(1-g^2)/(4*pi*pow(1+g*g-2*g*mu,1.5))`. Derive `mu` from the code's *photon incoming-propagation* and *scattered outgoing-propagation* direction conventions; don't blindly flip sun/ray signs. Check finite values for `mu=-1,0,1`, `abs(g)<1`, numerical normalization over 4*pi; test backlit vs frontlit cloud response.
- Density/weather: inspect Perlin-Worley combination, all value ranges and remaps; `coverage=0` should give nearly no cloud and `coverage=1` should give large coverage (unless documented inverse convention). Test large-scale continuity, height profile (finite base/top and grazing rays), weather/rain interpolation, nonuniform scale, world-space camera origin, ray normalization, `min(t_far,...)`/scene depth and horizon. Guard against repeating texture-cell appearance and harsh clipping.
- Compositing: `C_linear = L_linear + T * C_sky_linear` is valid **only if L is premultiplied accumulated in-scattering and T is final transmittance**. Verify linear vs sRGB path, no double gamma, no color-saturation clamp before physical accumulation, sky `R8G8B8A8_UNORM` output conversion and cloud/background occlusion.
- Spatial jitter in `[0,1)` ray-step units, ray step start/stop bounds, blue-noise vs hash correlation, no temporal history, and low-res upsample of thin silhouettes: isolate these as sampling/quality issues, **not necessarily formula bugs**.

Required debug outputs from an identical camera/weather/time: raw 3D noise slices, 2D weather map, coverage field, final density at multiple heights, normalized optical depth, transmittance, sun transmittance, in-scattering and final linear composite. Include numeric min/max/mean, NaN/Inf counts, hashes and 30-frame motion series. Run CPU reference on constant-density slab, empty/fully clouded, g=0, g=±0.5, near horizon, and rays starting inside cloud.
